# Identificação de Requisitos Funcionais e Não Funcionais

## 1. Objetivo

Este documento organiza os requisitos funcionais e não funcionais identificados para o sistema **Industrial Control Tower**.

## 2. Requisitos funcionais (RF)

Os requisitos funcionais descrevem os serviços e as funcionalidades que o sistema deve oferecer.

| Código | Requisito |
|---|---|
| RF01 | Permitir a autenticação de usuários. |
| RF02 | Permitir o cadastro de pedidos. |
| RF03 | Permitir o cadastro de matérias-primas. |
| RF04 | Permitir o controle de estoque. |
| RF05 | Permitir o cadastro de linhas de produção. |
| RF06 | Permitir o cadastro de ordens de produção. |
| RF07 | Apresentar indicadores operacionais. |
| RF08 | Identificar pedidos com risco de atraso. |
| RF09 | Identificar riscos de falta de materiais. |
| RF10 | Identificar gargalos produtivos. |
| RF11 | Gerar alertas operacionais. |
| RF12 | Permitir a importação de planilhas. |
| RF13 | Relacionar informações entre departamentos. |
| RF14 | Apresentar recomendações operacionais. |

## 3. Requisitos não funcionais (RNF)

Os requisitos não funcionais descrevem critérios de qualidade, segurança, desempenho e manutenção do sistema.

| Código | Requisito |
|---|---|
| RNF01 | Possuir interface responsiva. |
| RNF02 | Utilizar autenticação segura. |
| RNF03 | Manter a integridade referencial do banco de dados. |
| RNF04 | Possuir validação de dados nas APIs. |
| RNF05 | Apresentar mensagens de erro compreensíveis. |
| RNF06 | Possuir estrutura modular. |
| RNF07 | Ter mecanismos de proteção e controle de acesso aos dados. |
| RNF08 | Permitir evolução e futuras integrações. |

## 4. Resultado

Os requisitos funcionais definem o que o Industrial Control Tower deve realizar. Os requisitos não funcionais estabelecem condições de qualidade e segurança para seu funcionamento.

🚧  ## Requisitos funcionais e não funcionais

Este repositório reúne o levantamento dos requisitos do sistema. A proposta é deixar claro quais funcionalidades deverão existir e quais condições de qualidade precisam ser consideradas durante o desenvolvimento.

### Sobre o documento

| Parte | Conteúdo |
|---|---|
| Requisitos funcionais | Ações e recursos que o sistema deverá oferecer |
| Requisitos não funcionais | Qualidade, segurança e organização técnica |

### O que foi levantado

**Requisitos funcionais**
- Autenticação de usuários
- Cadastro de pedidos e matérias-primas
- Controle de estoque e ordens de produção
- Indicadores, alertas e identificação de riscos
- Importação de planilhas e recomendações operacionais

**Requisitos não funcionais**
- Interface responsiva
- Autenticação e proteção dos dados
- Integridade do banco de dados
- Validação das APIs
- Estrutura modular e possibilidade de expansão
